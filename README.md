Weather App 🌦️

A simple and responsive Weather App built using HTML, CSS, and JavaScript.
This project allows users to search for any city and view real-time weather details such as temperature, humidity, wind speed, and weather conditions.

🚀 Features
🔍 Search weather by city name
🌡️ Displays temperature in Celsius
💧 Shows humidity level
🌬️ Displays wind speed
☁️ Dynamic weather condition icons
📱 Responsive design for mobile and desktop
⚡ Real-time weather data using API
❌ Error handling for invalid city names
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and responsive UI
JavaScript (ES6) – Fetching API data and DOM manipulation
OpenWeatherMap API – Weather data source

⚙️ How It Works
User enters a city name.
JavaScript sends a request to the weather API.
API returns weather information in JSON format.
JavaScript parses the JSON data.
DOM updates dynamically to display weather details.
🔑 API Setup

This project uses the OpenWeatherMap API.

Steps:
Create a free account at
OpenWeatherMap
Generate your API key.
Replace the API key in script.js:
const apiKey = "YOUR_API_KEY";
▶️ How to Run the Project
Download or clone the repository.
git clone <your-repository-link>
Open the project folder.
Run index.html in your browser.
